# 14.02 browser-only probe

The isolated `/u1/` page is an offline-prepared diagnostic for a PS4 on 14.02.
It requires an explicit button press. It establishes the same browser memory
primitive used by the host, derives the WebKit and libkernel bases, reads the
15 gadget signatures and 24 syscall stub signatures checked by `jb-g.js`, and
then stops. Its JavaScript module graph contains only `core.js`, `mem.js`,
`int64.js`, `ps4_offsets.js`, and the two `/u1/` modules. It has no GoldHEN
asset fetch, ROP caller, Afterglow kernel import, or kernel write path.

The browser exploit can still close or hang the browser. The page records short
checkpoints in local browser storage; reopening `/u1/` displays the last one.
No addresses or kernel bytes are uploaded. The page's Content Security Policy
blocks network connections from its scripts.

A PASS means only that the supplied 14.02 browser and libkernel signatures
matched at runtime. It does not establish that the Afterglow kernel exploit
works, identify the earlier kernel panic, or make GoldHEN safe to start. The
normal 14.02 GoldHEN launch remains disabled.

Run `node tests/userland-probe-selftest.cjs` to verify the dependency boundary,
signature parity with the launcher, and positive/negative signature controls.
